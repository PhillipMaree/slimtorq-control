SlimTorq Simulator — User Manual FOC · PWM · Inverter · LCL · Encoder

SlimTorq is a closed-loop simulator for a slotless PMSM driven by Field-Oriented Control. The plant is an OpenModelica FMU (SlotlessPMSM_abc.fmu); the FOC controller, encoder, PWM inverter, and optional LCL filter run in Python and update the FMU at the inner sim step. Configure a run from the left panel, click Simulate, read the plots on the right. Every Simulate click runs a fresh sim and overwrites .temp/<family>_<variant>.parquet.

Install & run (Docker, one call)

Only requirement on the host is Docker Engine or Docker Desktop (docs.docker.com/get-docker). The published image bundles the Python deps, motor catalog, assets, and the pre-built FMU — no Python or OpenModelica toolchain needed.

  1. Install Docker on your PC (Linux, macOS, or Windows + WSL2).
  2. From the repo root run: docker compose up
  3. Open http://localhost:8000 in your browser.

Compose pulls (or builds) the image, mounts a named volume for the parquet artifacts, and starts the service. All runtime settings — port, CORS, frontend bundle path, artifact directory, catalog path — live in config/app.yaml and can be overridden per-env with the double-underscore convention (e.g. APP__PORT=9000, ARTIFACTS__DIR=/var/data).

Config panel — what each field does

Motor

variantSlimTorq catalog variant. Rs, Ls, ψm, p, J, Vdc are derived from this — no manual override.

Power stage

fpwmPWM carrier frequency (Hz). Sets the inner sim step (Tpwm/20 by default) and the current-loop bandwidth ≈ fpwm/9.4.
tdeadGate-driver dead time (s). 0 disables. Adds 5th/7th harmonic distortion to iabc.
PWM modesine, svpwm, dpwmmax, dpwmmin, dpwm1, or auto (svpwm ↔ dpwm1 at mi = 0.45/0.55). DPWMx clamps one phase to a rail, ~33% less switching loss.

Output filter (LCL)

enableInsert LCL low-pass between inverter terminals and motor.
fcTarget cutoff. Lf, Cf, Rd derived as Lf=Ls/4, Cf=1/(ωc2·Lf), Rd=√(Lf/Cf)/3. Hint line shows recommended bounds.

Encoder (inductive flux model)

NbitsAbsolute resolution; LSB = 2π/2N.
θoffsetConstant mounting offset (rad).
Ak, kk, φkThree cyclic harmonics: θerr = Σ Ak·sin(kk·θ + φk).
Ts,encEncoder sample period (s). ZOH between samples. Visible as sawtooth ω·Ts,enc on the encoder-error plot.

Trajectory

tend, tstepSim horizon and load-step time (s).
TLref/TepeakStep amplitude as fraction of catalog peak torque.
TfRun-length override; None = auto.

Timing

ΔtsimInner sim step (s); None = Tpwm/20. Must ≤ Tpwm/10 (enforced). Use ≤ Tpwm/50 for clean switching-mode results.

Current loop — PI tuning

Each rule is plant-aware: with the LCL filter off the plant is treated as the LR motor (Rs, Ls); with the LCL filter on it switches to the low-frequency equivalent Leq=L1+Lload, Req=R1+Rload, and rejects the tuning if the implied closed-loop bandwidth gets too close to the LCL resonance (ωbw ≤ ωres/10, conservative) or to fpwm/10.

Modulus OptimumKp=L·fpwm/3, Ki=R·fpwm/3. Default. ≈63° PM, 4.3 % overshoot.
Skogestad SIMCKp=L/(Tc+τ), Ti=min(L/R, k1·(Tc+τ)). Tc=None uses τ=1.5/fpwm; k1=1.44 default → ~3× sharper load-step rejection.
ManualType Kp/Ki directly. Bypasses the LCL safety gate.

Debug section

Inverter modeideal = vabcref straight to FMU; average = duty calc but cycle-averaged voltage (no dead-time, isolates scaling bugs); switching = real PWM compare + dead-time (default).
Sticky controls. Config panel stays pinned while the plot column scrolls. The Simulate button sticks to the bottom of the config panel so it's always reachable. Hard-refresh after CSS edits if the page looks stale.
Reading the plots 12 panels · what to look for

The plot column renders 12 Plotly figures from the most-recent parquet. Each figure pairs a measurement (solid) with its reference (dashed) using the same palette slot per signal. Steady-state metrics are computed on the trailing 80 % of samples to skip the load-step transient.

Tracking

Torque (TLref vs Te), iq* vs iq, id* vs id. Each subplot title carries the steady-state RMS reference-tracking error in %.

PI performance

ed, eq errors; vdref, vqref; |vdq| vs the Vmax=Vdc/2 vector limit (red-dotted). PI-saturation rug strip below shows when the integrator was frozen.

dq round-trip

vdactual−vdref, vqactual−vqref, reconstructed from logged post-inverter vabc via Clarke+Park. Cycle-average ≈ 0 proves inverter scaling is correct. Switching-mode shows ripple; average/ideal modes show flat zero.

iq zoom

5×Tpwm window in steady state with carrier-valley guides. Shows the controller's actual measurement noise vs reference.

iq FFT, ω FFT, ia FFT

Log-magnitude spectra (trailing 80 %, DC removed). Switching ripple shows at 2·fpwm in iq, at fpwm ± n·f1 in ia. Dead-time signature: 5th/7th of the electrical fundamental in ia.

Phase currents (abc)

ia, ib, ic overlaid. With switching enabled and no filter, ripple amplitude Δipp ≈ Vdc·Tpwm/(8·Ls).

Phase voltages

varef dashed, post-inverter va faint solid, and (when LCL on) vamotor at filter output as medium solid. With filter on, the motor trace should hug the smooth ref while the inverter trace hits ±Vdc/2.

PWM duties

da, db, dc. With svpwm/dpwmx the shape clearly departs from pure sine — visual confirmation the zero-sequence injection took effect.

Encoder error

wrap(θmtrue−θmmeas) in mrad. Dashed envelope at ω·Ts,enc is the ZOH bound; the trace should ride inside this band. Excursions outside it are cyclic harmonics + quantization + offset.

Speed + saturation

ωmtrue vs ωmmeas, plus a rug strip marking d/q PI saturation events.

Observer (LCL only)

Appears next to Signal Processing when the LCL filter is enabled. Two panels overlay the measured dq currents (idmeas, iqmeas) with the Luenberger observer's three estimated LCL states (i1, vC, im) and the derived capacitor current ic = i1 − im. The accompanying FFT shows where ic's spectral energy sits — peaks near the LCL resonance are what future active damping vdamp = −Kd·ic will target.

Workflow tips

  • Diagnose noise: bypass with Inverter mode = ideal. If clean, the inverter is the source. Then try average — non-zero mean Δvd in the dq round-trip means a scaling bug; flat zero means switching ripple is the issue.
  • Tune for disturbance rejection: switch PI to Skogestad, lower k1 toward 1.44. Tighter integrator → smaller err % in the tracking subplot titles.
  • Pick fc for the LCL: aim near fpwm/10 for ~40 dB carrier attenuation. The hint under the input gives the loop-safe floor for the current fpwm.
  • Sample-rate aliasing check: at fixed fpwm, halve Δtsim. If noise drops, it's edge quantization in the modulator, not real inverter physics.
  • Output: each run writes .temp/<family>_<variant>.parquet with full per-sample log and slimtorq.* metadata (params hash, tuning, modes, filter values).
